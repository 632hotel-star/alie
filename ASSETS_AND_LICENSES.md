# Assets and licences

## Artwork supplied by the project owner

| File (`assets-src/`) | Used as | Notes |
|---|---|---|
| `1.webp` | brand mark | blue ring, laurel profile, star. Used in the header, the hero morph, the coach avatar, the finale and the box print. Also exported as the favicon and Open Graph image. |
| `2.webp` | stage 2, the beginner | hero figure, progress camera / slider, finale |
| `3.webp` | stage 3, the strong | Train chapter figure, progress slider, finale |
| `4.webp` | stage 4, the beast | Commit chapter figure, finale |
| `5.webp` | stage 5, the iron-eater (gold) | finale |

`scripts/process_assets.py` only crops to the visible bounds and resizes (WebP, alpha kept). Nothing is redrawn or recoloured. The artwork's licence is the owner's; confirm you hold the rights before publishing.

### Not supplied (gaps to fill)

* **Stage 1, "المهمل"**: the site is built for it (hero glimpse and finale sequence). Until the drawing is added, the hero opens with stage 2 and the evolution shows four stages. See README → "Replacing artwork".
* **Section-specific illustrations** from the brief (nutrition figure with food, a figure at a mirror for measurements, a distinct supplements figure with a creatine tub). Not supplied, so the chapters reuse the existing characters (Train: stage 3, Commit: stage 4, Progress: stages 2 to 4) and the brand mark. No substitute art was generated.

## Generated by this project

| Asset | How |
|---|---|
| `public/posters/*.webp` | rendered from the site's own procedural WebGL props (`qa/poster.mjs`); used only when WebGL is unavailable. |
| 3D meal box, its printed faces, barcode | built in code (`src/components/gl/foodbox.ts`). The barcode is a valid EAN-13 structure for the **demo number** `6281234567895`, not a real product. |
| Muscle mannequin | built in code from ellipsoids, rendered by a custom engraving shader (`mannequin.ts`). |
| `public/og.png`, `src/app/icon.png`, `apple-icon.png` | composed from the supplied artwork by `process_assets.py`. |

No stock photography, no third-party illustrations, no screenshots of any real app.
